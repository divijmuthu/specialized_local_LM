# 🚀 SLM Business Insights System

A comprehensive **Small Language Model for Business Insights (SLM-BI)** system that provides powerful AI-driven business intelligence capabilities to drive revenue increases and cost reductions.

## 🎯 What This System Does

The SLM Business Insights system provides:

- **📈 Customer Segmentation & Targeting** - Identify and target high-value customer segments
- **😊 Sentiment Analysis** - Analyze customer feedback and sentiment trends
- **📊 Sales Forecasting** - Predict future sales and demand patterns
- **💰 Price Optimization** - Optimize pricing strategies for maximum revenue
- **⚠️ Churn Prediction** - Identify customers at risk of churning
- **🛒 Market Basket Analysis** - Discover product associations and cross-selling opportunities
- **📦 Supply Chain Optimization** - Optimize inventory and supply chain operations
- **🔍 Anomaly Detection** - Identify unusual patterns and potential issues
- **🤖 Recommender Systems** - Provide personalized product recommendations
- **📈 Time Series Analysis** - Analyze trends and seasonal patterns
- **🕸️ Graph Neural Networks** - Analyze customer and product relationships
- **🎯 Reinforcement Learning** - Dynamic optimization of business strategies
- **🔬 Causal Inference** - Understand cause-and-effect relationships
- **📝 NLP Insights** - Extract insights from text data

## 🚀 Quick Start

### Option 1: Automated Setup (Recommended)
```bash
# Run the automated setup script
python3 setup.py

# This will:
# - Check system requirements
# - Create virtual environment
# - Install all dependencies
# - Run initial tests
# - Provide next steps
```

### Option 2: Manual Setup
```bash
# Create virtual environment
python3 -m venv slm_env
source slm_env/bin/activate  # On Windows: slm_env\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the system
python3 app.py --mode all
```

## 📊 System Architecture

The system uses a hierarchical model architecture with:

- **High-level Models**: Strategic insights and business recommendations
- **Low-level Models**: Specific ML models for different business functions
- **BERT/DistilBERT**: For text processing and NLP tasks
- **Deep Supervision**: Multi-task learning for improved performance
